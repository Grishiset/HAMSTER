ХОМЯК И МАЛЫШКА — версия для телефона
=====================================

Это веб-приложение (PWA). После установки у него своя иконка на экране «Домой»,
оно открывается на весь экран без строки Safari и работает без интернета.

1. Выложить папку на любой HTTPS-хостинг, например GitHub Pages:
   - на github.com создать публичный репозиторий (например, hamster);
   - Add file → Upload files → перетащить ВСЁ содержимое этой папки
     (index.html, sw.js, manifest.webmanifest, три картинки-иконки и папку v8) → Commit;
   - Settings → Pages → Source: Deploy from a branch, Branch: main, папка / (root) → Save;
   - через 1–2 минуты игра будет по адресу https://ИМЯ.github.io/hamster/

2. Установить на iPhone:
   - открыть этот адрес в Safari;
   - кнопка «Поделиться» → «На экран „Домой“» → «Добавить».
   На Android: Chrome → меню ⋮ → «Установить приложение».

3. Первый запуск — с интернетом (подгружаются шрифты), дальше игра работает офлайн.

Прошлые версии: папка versions/ (versions/v8, versions/v9). В игре ссылок на них нет.
Чтобы откатиться, скопируй index.html нужной версии в корень репозитория,
поправив пути к иконкам и manifest с ../../ на пустые, — или просто попроси Claude.

Прогресс хранится на самом телефоне, внутри установленного приложения.
Если удалить иконку, прогресс сотрётся.
